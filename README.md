# AscendSTEMAcademy
Umbrella school

## Game Drawer

Browser mini-games for the Ascend STEM Academy site, in [`games/`](games/).
Each one is a single self-contained page with no build step — drop it into the
drawer as an iframe. See [`games/README.md`](games/README.md) for integration.

- ⚡ **[Circuit Clash](games/circuit-clash/)** — two-player STEM duel. Challenge a
  classmate by name, trade timed questions across six subject tracks, steal their
  misses, and the winner takes a downloadable badge.
