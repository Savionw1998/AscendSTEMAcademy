=== Ascend Site Updates ===
Stable tag: 1.0.0
Requires PHP: 7.4
License: GPLv2 or later

Reviews and applies a packaged set of content updates to Ascend STEM Academy's
Elementor pages, with a before/after preview, per-change or per-page apply,
and a one-click "Restore original" for every page it changes.

== Use ==
1. Upload the zip in Plugins > Add New > Upload, then activate.
2. Open Tools > Ascend Site Updates.
3. Review each row. "Ready" rows apply cleanly; "Needs a look" rows are skipped
   because the page text changed since the updates were written.
4. Apply one row, one page, or everything. A backup of each page is kept.

It also adds:
* Redirects: /blog/ -> /posts/ and /register/ -> /registration/ (Settings tab)
* Sibling discount: 10% off each additional enrollment in one order (Settings tab)
* [ascend_latest_guides count="3"] and [ascend_latest_guides count="50" filters="1"]
* Speed check tab: overlapping or unused plugins, with Deactivate buttons

== Developers ==
Changes live in data/changes.json, generated by tools/build_changes.py.
